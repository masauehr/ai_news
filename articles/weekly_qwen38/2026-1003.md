# 生成AI週次ダイジェスト（9/26〜10/3）

今週は、Google が出力100万トークンの新フロンティアモデル **Gemini 4 Argon** を発表し、OpenAI が常時稼働型エージェント **dots** を提供開始、Anthropic が **Claude Code** の拡張機能「mod」対応を発表するなど、主要3社が軒並み動きを見せた1週間でした。一方、国内では総務省の調査で生成AIの個人利用が9%どまりという結果が再注目され、デジタル庁のOSS「源内」活用や国産LLMの動向も話題に。ローカル/軽量モデルでは、Qwen3.8-27Bを9分の1に圧縮した **Bonsai-2-27B** や、判断専用のオープンソース意思決定モデル **Laya** が注目を集めました。

## 1. Google、新フロンティアモデル「Gemini 4 Argon」を発表（出力100万トークン）

Google が新たなフロンティアAIモデル **Gemini 4 Argon** を発表しました。最大の特徴は、出力上限を従来から100万トークンへ大幅に拡大し、長期にわたる自律的な推論と作業に優れる点です。Claude Opus 5.5 や GPT-6 Astra の最大出力12.8万トークンに対し、約8倍の規模を誇ります。

ベンチマークでは、業務自動化の AutomationBench で51.3%（Opus 5.5の42.5%、Astraの41.4%を上回る）、法務の Harvey's Legal Agent Benchmark で19.6%（Opus 5.5の3.8%、Astraの5.4%を大きく上回る）、財務リサーチの Vals Finance Agent v2 で65.4%と、高度なナレッジワーク・コーディング・サイバーセキュリティ分野で強みを見せています。

提供は、審査を経たサイバー防御組織が参加できる「Fairwind Program」（世界650以上の組織が参加）から開始し、その後有料API顧客と Google AI Ultra ユーザーへ段階的に拡大する方針です。導入価格は100万トークンあたり入力2ドル・出力10ドル（キャッシュ済み入力は95%引き）で、Claude Sonnet 5.5 や GPT-6.1 Sol と同等、最上位の GPT-6 Astra や Claude Fable 5.1 より安価な中位モデルに位置づけられています。

## 2. OpenAI、常時稼働型AIエージェント「dots」を提供開始

OpenAI は開発者向けイベント「DevDay 2026」で、AIエージェント **dots** を発表しました。GPT-6 Astra を核に、クラウド上で常時可動するエージェントで、1体ごとに専用のクラウドコンピューターとウェブブラウザを持ち、プラグイン経由で4000以上のアプリと連携します。

ユーザーが逐一指示を出す必要はなく、目標を与えればフィードバックから学びつつ24時間作業を続けられます。初期テストでは、ユーザーが請求書を送り忘れていることに dot が気づき、指示を待たずに作成して承認後に送信した例も報告されています。話しかけていない間も「先回りリサーチ」と呼ぶ動作を続け、メールやカレンダーから情報を集めて dot 用のメモに残します。

安全性面では、メール送信やファイル変更などアカウントに影響する操作は「自動レビュー」が実行前に確認し、パスワード変更や口座間の送金は必ず本人確認を求めます。ChatGPT のほか Slack や Teams、音声通話からも操作可能です。提供は ChatGPT Pro（月額100ドル〜）と Business Premium の18歳以上利用者に順次開始で、最初の1体は追加料金なしです。同日には新モデル「GPT-6.1 Sol」や共同作業スペース「ChatGPT Space」も発表されました。

- 出典: [OpenAIのAIエージェント「dots」提供開始（Techno Edge）](https://www.techno-edge.net/article/2026/09/30/5540.html)
- 出典: [OpenAI News（OpenAI 公式ニュース）](https://openai.com/news/)

## 3. Anthropic、Claude Code が拡張機能「mod」に対応

Anthropic が、AIコーディングツール **Claude Code** の外観や動作をユーザーの好みでカスタマイズできる拡張機能「mod」に対応しました。UI や動作をカスタマイズでき、Claude 自身に書かせて作成することも可能です。

## 4. 軽量・ローカルモデルの台頭：Bonsai-2-27B と意思決定モデル「Laya」

ローカル/軽量モデルでは2つの話題が注目されました。

**Bonsai-2-27B** は、Prism ML が公開した270億パラメータのマルチモーダルAIモデルで、Qwen3.8-27B をベースに重みを3値（-1, 0, +1）で表現する圧縮技術を採用。フル精度モデルから9倍以上縮小した5.9GBのメモリサイズを実現しつつ、ベースモデルのトータルベンチマーク性能の98.2%を維持します。NVIDIA GPU（CUDA）や Mac・iPhone・iPad などの Apple デバイス（MLX）でも動作可能で、Apache 2.0 ライセンスです。

**Laya** は、インドの AI 企業 Convai Innovations が開発したオープンソース（Apache 2.0）の意思決定AIモデルです。一般的な LLM が文章を1単語ずつ生成するのに対し、Laya はあらかじめ設定した選択肢に対する確率を1回の計算（GPU環境で約33ミリ秒）で直接予測します。ハルシネーションを排除しつつ、システムが直接扱えるデータを一瞬で出力でき、先行サービス Jev に対し約7.8倍高速とされます。100以上の言語を自動検知し、最大8192トークンの長文処理にも対応します。

## 5. 国内動向：生成AIの個人利用は9%どまり、デジタル庁「源内」活用と国産LLM

国内では、総務省の調査で生成AIを利用している個人が **9.1%** にとどまり、中国（56.3%）、米国（46.3%）、英国（39.8%）、ドイツ（34.6%）と大きな開きがある結果が再注目されています。利用しない理由で「使い方がわからない」が4割超、企業向けでは業務利用が46.8%（米国84.7%、中国84.4%）と、導入の慎重さがうかがえます。

行政・国産AIの面では、デジタル庁が政府職員向けに開発してきたOSS「源内（げんない）」を自治体や民間が活用する動きが広がっています。大分市は、デジタル庁OSS「源内」を活用した生成AIサービスを自治体で初めて LGWAN 環境から利用可能にし、ハルシネーション抑制や音声書き起こし、多言語翻訳、画像生成に対応しました。

国産LLMでは、PFN のフルスクラッチ開発 **PLaMo 3.0 Prime**（Reasoning/Non-reasoning の2モデル）、SB Intuitions の **Sarashina3** シリーズ、Sakana AI の **Fugu**、一創の **LLM-jp-4**（独自トークナイザー v4.0 採用）などが主要モデルとして位置づけられています。

## 7. 1-bit LLM / BitNet の最前線

極端な低ビット化（1-bit LLM）は、推論コスト削減の切り札として注目を集め続けています。Microsoft Research の **BitNet b1.58** は、重みと活性化を1.58ビットで表現する LLM 変種で、LLaMA 同等の性能を維持しつつ計算コストを大幅に削減する可能性を示しました。

2026年に入ると「Scaling Laws for 1-bit Transformers」などの追加論文や、NVIDIA による低精度推論への対応、BitNet × Qwen3.5(4B) × Ollama × Docker によるローカル実行環境の構築例が報告されています。Zenn では「1-bit LLMとBonsai：極限軽量化の最前線」が論文ベースで整理されており、BitNet と Bonsai 系の圧縮技術が並走する状況です。
