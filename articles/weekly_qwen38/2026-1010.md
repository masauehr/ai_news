## 2. Cloudflare、判断特化型オープンモデル「Clef / Jeff」を公開 — Jev 超えを宣言

Cloudflare がオープンソースの意思決定モデル **Clef** と **Clef-flash** を Apache 2.0 ライセンスで公開。
文章生成ではなく「どのカテゴリに属するか」「緊急か否か」などの定型回答を低コスト・高速に出力する
判断特化型モデルで、テキストだけでなく画像分類にも対応する。

- 基盤は **Qwen3.8-27B**（Clef）と **Qwen3.5-9B**（Clef-flash）をベースに追加学習。
- 意思決定モデルの評価指標「Jev Decision Index」でトップに立ち、10ベンチマーク中8つで先行モデル
  「Jev」を上回る結果を記録。
- 関連して、8億パラメータの軽量判断特化AI **Jeff** が無料公開。Qwen3.8-27B と比較し、
  正答率は 86.6%→95.3% に向上、1件あたり処理時間は 8.1秒→250ミリ秒（約37.7倍高速化）。
  LLM の手前に配置するフィルター役として、簡単な判定は Jeff が捌き、複雑な問題だけ大型モデルに
  委ねる構成が想定される。v1.2 ではスパム判定やカスタマーサポート振り分けなど9種のアダプター提供、
  全パーツ同時読み込みでも GPU メモリ消費は約1.96GB。

## 5. AIエージェント基盤の動向 — MCP標準化と「余計な機能を足さない」OSS

- **OpenDots**（CopilotKit 開発、MITライセンス、アルファ版）: 常時稼働 AI エージェントの作業環境を
  構築できる OSS テンプレート。Web・モバイル対応で、テキストチャット・音声通話・Slack を横断。

- 背景として、AutoGen は 2025年10月にメンテナンスモード入りし、後継の **Microsoft Agent Framework**

## 8. 1-bit LLM / BitNet の動向

Microsoft の 1-bit LLM 研究は継続。

- **BitNet.cpp**: 1-bit LLM（BitNet b1.58 等）向けの公式推論フレームワーク。CPU 上で 100B パラメータ
  モデルを約6倍高速化、能耗を約82% 削減。
- 最新研究では、権重を 1.58-bit に量子化しつつ、**4-bit 活性化値量子化**で次世代 GPU の 4-bit 計算を
  活用する方向性が検討されている。
- 初のオープンソース 1-bit LLM「BitNet b1.58 2B4T」も登場し、エッジデバイスでの実用化が視野に。
