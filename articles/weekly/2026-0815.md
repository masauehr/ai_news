# 生成AI週次ダイジェスト（8/8〜8/15）

今週は、GoogleのGemini 3.7 Flashリリース、AnthropicのClaude Opus 5/Sonnet 5および透かし導入、OpenAIのLinuxデスクトップアプリ公開など、主要モデルのアップデートが相次いだ話題となりました。また、Geminiアプリの月間アクティブユーザー10億人突破や、欧米3大AI企業のAPI脆弱性暴露など、注目ニュースも多数ありました。

## 1. Google Gemini 3.7 Flashリリース — コーディング・エージェント性能を大幅強化

Google DeepMindは8月12日、Gemini 3シリーズの最新モデル「**Gemini 3.7 Flash**」を正式リリースしました。[Introducing Gemini 3.7 Flash（Gemini 3.7 Flashの発表）](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/)

今週時点でGoogleが3ヶ月間で3つ目のGemini Flashモデルを発表。コーディング精度とエージェントタスクの性能向上を謳い、Gemini Spark（Google AI Pro/Ultra契約者向け）でも8月12日より利用開始されます。API価格は年末まで$0.75/$3.75 per 1M tokens（入力/出力）の割引価格が適用されます。

技術面では、推論基盤へのアルゴリズム改善が施され、「Intelligence vs. Time per Task」のパレート最適 frontier を強化。Gemini Robotics ER 2やWeatherNext（サイクロン予測モデル）など、マルチモーダル・ロボティクス分野での展開も進んでいます。

- [Gemini 3.7 Flash - Model Card](https://deepmind.google/models/model-cards/gemini-3-7-flash/)
- [Google DeepMind Blog: Gemini Robotics ER 2](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/gemini-robotics-er-2/)
- [WeatherNext: AI model achieves breakthrough in forecasting cyclones](https://deepmind.google/blog/weathernext-ai-model-achieves-breakthrough-in-forecasting-cyclones/)

## 2. Anthropic Claude Opus 5 / Sonnet 5リリース — 推論・エージェント性能を再定義

Anthropicは8月上旬、Flagshipモデル「**Claude Opus 5**」および「**Claude Sonnet 5**」をリリースしました。[Introducing Opus 5（Opus 5の発表）](https://www.anthropic.com/news/claude-opus-5)

Opus 5は、コーディング性能の強化、より高度なエージェント機能、専門作業の精度向上を特徴としています。コンテキストウィンドウは100万トークンをサポート。API価格は$5/$25 per 1M tokens（入力/出力）。Sonnet 5は「作業用ホースモデル」と位置づけられ、文書処理・分析・日常業務で高い性能を発揮します。

またAnthropicはFable 5シリーズの再デプロイや、生物学セーフガードの改善も発表しています。[Redeploying Fable 5](https://www.anthropic.com/news/redeploying-fable-5)

## 3. Claude Text Watermark — EU AI法対応の不可視透かし導入へ

Anthropicは8月12日、Claudeの生成文章に**電子透かし（Text Watermark）**を導入すると発表しました。[Claude Text Watermark（Claudeのテキスト透かし）](https://www.anthropic.com/news/claude-text-watermark)

これはEU AI法第50条(2)に基づく合成コンテンツ透明化への対応で、Claudeの出力に統計的な透かしを埋め込み、AI生成文章かどうかを判別可能にします。透かしは編集しても残る「見えないテキスト」として実装され、改ざん困難な方式を採用。

この動きに対し、一部Claudeユーザーからは「職務上の不正や学業での cheating 検出に利用されるのではないか」と懸念の声が上がっています。[Some Claude users are mad...](https://techcrunch.com/2026/08/12/some-claude-users-are-mad-that-anthropics-new-watermarks-will-catch-them-cheating-at-their-jobs-classes/)

他の主要AIラボも同様の透かし導入を進めており、業界全体の標準化が進む見込みです。

## 6. OpenAI・Anthropic・GoogleのAPI脆弱性暴露 — 推論チェーンが盗まれる危険性

OpenAI、Anthropic、Googleの3社が提供するLLM APIに、重大なアーキテクチャ脆弱性が発見されました。[OpenAI, Anthropic, Google API Flaw Let Weaker AI Models Decode...](https://thehackernews.com/2026/08/openai-anthropic-google-api-flaw-let.html)

主要AIプロバイダーがFlagship LLMの内部「chain-of-thought（推論チェーン）」を保護する際の実装に欠陥があり、攻撃者が暗号化された推論ブロックをセッション間でリプレイでき、内部推論・APIキー・パスワードなどを復元可能でした。研究者は315,320の推論ブロックを解読し、公開エージェントログから生APIキーを抽出することに成功しています。

これはAIセキュリティの重大な課題であり、各社による修正パッチが急がれています。

- [OpenAI, Anthropic, and Google LLM APIs vulnerability Exposes...](https://cybersecuritynews.com/top-ai-models-apis-flaw-exposes-hidden-reasoning/)
- [AI Reasoning Traces Stolen From Anthropic, OpenAI, Google · TFTC](https://www.tftc.io/ai-reasoning-traces-stolen-anthropic-openai-google-global-key)
