# 生成AI週次ダイジェスト（9/5〜9/12）

## 1. OpenAI、Agents API の公開ベータ開始

OpenAIは9月10日、長期タスク対応の「Agents API」を公開ベータ開始した。同APIにより、複数ステップのタスク実行やユーザーのアクションを待つ必要があるワークフローを実装できる。企業向けアプリケーション開発の効率化が期待される。

参照: [TECH NOISY — AI Daily News 2026-09-12](https://tech-noisy.com/2026/09/12/ai-daily-news-2026-09-11/)

## 2. Anthropic、Claude Enterprise 向け分析機能「スマートレポート」ベータ開始

Anthropic は同日、Claude Enterprise 向けの分析機能「スマートレポート」をベータ公開した。契約および使用データの自動分析機能により、企業における AI 利用の最適化が可能になる。クラウドモデルの中ではパフォーマンス・セキュリティ面で優位性を保っている。

参照: [TECH NOISY — AI Daily News 2026-09-12](https://tech-noisy.com/2026/09/12/ai-daily-news-2026-09-11/)

## 3. Sakana AI、複数モデル自動選択機能「Fugu Max」「Fugu Ultra v2」をリリース

Sakana AI は9月11日、複数のLLMを自動選択・実行する「Fugu Max」と高性能版「Fugu Ultra v2」をリリースした。Maxは競合比40～60%安価な料金体系を実現し、Ultra v2はChartography等のベンチマークで48.3点を記録するなど高性能。タスク特性に応じた最適なモデル選択が自動で行われ、コスト効率と精度の両立が実現した。

参照: [TECH NOISY — AI Daily News 2026-09-12](https://tech-noisy.com/2026/09/12/ai-daily-news-2026-09-11/)

## 4. デジタル庁、国産AI「源内」で7モデル実証・国立情報学研究所がマルチモーダルモデルを公開

デジタル庁の行政向けAI基盤「源内」では、NTTデータ・NEC・富士通・PFN等が選定した国産LLM 7モデルが全府省庁約18万人対象で実証中である。一方、国立情報学研究所（NII）は「llm-jp-4-8b-thinking」をマルチモーダル化した視覚言語モデル「LLM-jp-4-VL 9B」を公開。国産AI開発の実用化が加速している。

参照:
- [デジタル庁「源内」国産AI7モデル選定](https://www.sbbit.jp/article/cont1/182108)
- [デジタル庁のガイドライン 2026年6月12日](https://www.digital.go.jp/assets/contents/node/information/field_ref_resources/decb64eb-f26e-41cb-8d37-f3dd173108b8/59054b35/20260612_resources_standard_guidelines_guideline_01.pdf)

## 5. 日本企業のAI実装動向、エージェント時代へ加速

日本経済新聞社は9月1日「NIKKEI KAI MCP」でModel Context Protocol対応を開始し、生成AI との連携がより柔軟に。GMO TECHは「店舗AIエージェント」β版提供、JAPAN AI・CONOCは建設業向けAIエージェント2種を提供開始するなど、「使う」から「任せる」時代へシフトしている。9月15日には赤坂インターシティで「AI資本経営フォーラム2026 in Autumn」が開催される。

## 6. Google Gemini 3.8 Flash / Flash Cyber 発表、DeepSeek V4.1 Flash リリース

Google は Gemini 3.8 Flash（テキスト・画像対応）とサイバーセキュリティ特化の Flash Cyber を同時発表。Cyber版は Chrome Security で従来比2.6倍正確なパッチ生成を実現した。DeepSeek も9月10日に V4.1 Flash をリリースし、軽量モデルの性能競争が激化している。

参照: [TECH NOISY — AI Weekly News 2026-08-31〜09-06](https://tech-noisy.com/2026/09/07/ai-weekly-news-2026-08-31-2026-09-06/)

## 7. ローカルLLM・エージェント技術の進展

Ollama は v0.32系でApple Silicon 向けMLXエンジンを搭載し、Gemma 4ではマルチトークン予測により約90%の高速化を実現。Qwen3.8-27B（8月15日開源）はローカル展開の「黄金サイズ」と称賛され、2日でダウンロード100万超、500超の量子化版が公開された。Microsoft Agent Framework がv1.0（.NET/Python）として2026年4月に Production-ready 版をリリースし、AutoGen からの移行も公式サポートされている。

参照:
- [Ollama Library — Qwen3.8](https://ollama.com/library/qwen3.8)
- [Microsoft Learn — Agent Framework Migration Guide](https://learn.microsoft.com/ja-jp/agent-framework/migration-guide/from-autogen/)

## 8. 1-bit LLM「BitNet」の進化、エッジAI推論の革新

Microsoft は「BitNet.cpp」（2025年5月開源）で1-bit大言語モデル用CPU推論フレームワークを提供。BitNet b1.58は重みを圧縮し速度6倍・エネルギー82%削減を実現。BitNet a4.8 では4-bit activations を採用し、さらなる最適化が進んでいる。メモリ約25GB の消費級CPU で100Bパラメータモデル動作が可能となり、エッジAI推論が革新されている。

参照:
- [Microsoft BitNet Official](https://bitnet.live/)
- [GitHub — microsoft/BitNet](https://github.com/microsoft/BitNet)

## 9. MCPの企業導入加速、アドエビスなど広告計測連携
