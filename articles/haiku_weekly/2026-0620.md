# 生成AI週次ダイジェスト（6/13〜6/20）

## 🎯 今週のハイライト

2026年6月の第2週は、大規模言語モデルの新展開、エージェントAIの進化、日本国内の生成AI推進施策が相次いで発表された重要な週となりました。特にGoogleの新モデル発表、ChatGPTの定期実行機能、そして国産LLM選定に関する重大なニュースが注目を集めました。

---

## 📰 主要トピック

### 1. **Google、Gemini Omni と Gemma 4 12B を発表**
GoogleのDeepMindチームが複数の大規模言語モデルの新版を発表しました。特に注目は「Gemini Omni」と「Gemma 4 12B」で、後者はエンコーダー不要の統合マルチモーダルモデルとして位置づけられています。

- 出典: [Introducing Gemini Omni（Gemini Omniの発表）](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)
- 出典: [Introducing Gemma 4 12B（Gemma 4 12Bの発表）](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/)

Googleはさらに「DiffusionGemma」という4倍高速なテキスト生成技術も公開し、推論効率の向上に注力している様子が伺えます。

### 2. **ChatGPT、定期タスク実行機能「スケジュール」を追加**
OpenAIはChatGPTに「タスク（Scheduled Tasks）」という新機能を追加し、定期的に実行されるワークフローの自動化を可能にしました。入荷確認やユーザーの毎朝のまとめ作成などが自動実行できるようになります。

- 出典: [ChatGPTに定期タスク実行の新機能「スケジュール」](https://www.techno-edge.net/article/2026/06/19/5205.html)

この機能により、生成AIの活用範囲が「会話相手」から「自動執行エージェント」へ拡大しています。

### 3. **Google、Gemini搭載スマートスピーカーを1万6800円で発売**
Googleは新型の「Google Home」スマートスピーカーを発表。Geminiを搭載し、定型文以外の複雑なフレーズやコマンドに対応できるようになりました。サブスクリプションオプションでのライブ会話機能も提供予定です。

- 出典: [Gemini搭載の新Google Homeスピーカー発売](https://www.techno-edge.net/article/2026/06/18/5199.html)

### 4. **【国内動向】デジタル庁、全府省庁18万人向けの「源内」実証を5月から開始。国産LLM 7件を選定**

日本のAI戦略における最重要ニュースが本週です。デジタル庁は「ガバメントAI」構想の中核となる生成AI利用環境「源内（げんない）」を、2026年5月から全府省庁約18万人の職員を対象に大規模実証を開始しました。

**選定された国産LLM 7件（「7人の侍」）：**
- NTTデータの「PLaMo」シリーズ
- Sarashina 2
- その他5件の国産モデル

- 出典: [デジタル庁が国産ai「7人の侍」選定](https://www.sbbit.jp/article/cont1/182108/)
- 出典: [政府の生成AI基盤「源内」とは](https://note.com/zouplans/n/nb7d48809d758/)
- 出典: [ガバメントAI「源内」をオープンソースとして公開](https://digital-gov.note.jp/n/n84aeba282e60/)

この施策は単なる行政デジタル化ではなく、国産LLM産業の育成と日本語特化型AI開発を国家レベルで推進する重要なシグナルとなっています。

### 5. **国立情報学研究所（NII）、LLM-jp-4シリーズを公開。GPT-4o越えの日本語性能を達成**
4月3日に国立情報学研究所は新型国産LLM「LLM-jp-4」シリーズを発表。約12兆トークンの良質コーパスで学習し、複数のベンチマークでOpenAIの「gpt-oss-20b」やQwen3-8Bを上回る日本語処理性能を実現しました。

公開されたモデル：
- LLM-jp-4 8Bモデル
- LLM-jp-4 32B-A3Bモデル（アーキテクチャ専用）

- 出典: [国立情報学研究所の LLM-jp-4 公開](https://www.nii.ac.jp/news/release/2026/0403.html)
- 出典: [NIIが12兆トークン国産LLM、日本語性能でGPT-4o越え](https://www.sbbit.jp/article/cont1/183900/)
- 出典: [国産LLM「LLM-jp-4」公開](https://note.com/pika2_hikaru/n/n11992fb9e79e/)

### 6. **1兆パラメータの中国系コーディングAI「Kimi-K2.7-Code」が無料・商用利用可で登場**
中国のAI企業が開発した1兆パラメータのコーディング特化モデル「Kimi-K2.7-Code」が無料で商用利用可能な状態で公開されました。また、アリババの衛星画像3D生成AI「ABot-Earth 0.5」も注目を集めています。

- 出典: [1兆パラメータのコーディングAI「Kimi-K2.7-Code」が無料・商用利用可](https://www.techno-edge.net/article/2026/06/19/5203.html)

### 7. **AI業界の新展開：Midjourneyのハードウェア参入、xAIの新型スパの発表**
話題のAI画像生成企業Midjourneyが次のステップとして、超音波CT「Midjourney Scanner」を備えた「次世代スパ」を2027年中にオープンすることを発表。AIの利用シーンが医療・ウェルネス領域へも拡大しています。

- 出典: [Midjourneyがハードウェアに参入](https://www.techno-edge.net/article/2026/06/18/5200.html)

### 8. **AIエージェントとMCP（Model Context Protocol）の統合進化**
OpenAIとMicrosoftがModel Context Protocol（MCP）への対応を発表したことで、AIエージェントと外部システム・ツールの連携が標準化されつつあります。AutoGenなどのエージェントフレームワークもMCP対応が進み、「AI界のUSB-C化」が現実化しています。

- 出典: [Claudeに記憶を持たせてみた〜MCPとMemory機能の導入](https://qiita.com/natsugure/items/a887aa86bfdf39bb2104/)
- 出典: [What is the Model Context Protocol（MCP）?](https://modelcontextprotocol.io/)

### 9. **1-bit LLM「BitNet」の進化：超効率的なローカルLLM実行の現実化**
Microsoftが開発した1-bit LLM「BitNet」が100億パラメータ規模の実用化段階に入りました。重みを{-1, 0, 1}の3値で表現することで、CPUでの推論を可能にし、エネルギー効率と処理速度の革新的な改善を実現しています。

- 出典: [BitNet a4.8: 4-bit Activations for 1-bit LLMs](https://www.microsoft.com/en-us/research/publication/bitnet-a4-8-4-bit-activations-for-1-bit-llms/?lang=ja)
- 出典: [BitNet 100B Models on CPU](https://api7.ai/ja/blog/bitnet-100b-cpu-intelligent-llm-routing)

### 10. **生成AIの企業活用：経営企画・資料作成・顧客対応の効率化が進展**
国内では生成AIの企業導入がさらに加速。経営企画部門での活用、営業資料の自動生成、社内問い合わせ対応の自動化など、業務プロセス全体への浸透が報告されています。

- 出典: [生成AIを経営企画に活用する方法](https://ainow.ai/2026/06/20/278185/)
- 出典: [生成AIで社内問い合わせを自動化](https://ainow.ai/2026/06/16/278175/)
- 出典: [生成AIで資料作成を効率化する方法](https://ainow.ai/2026/06/16/278172/)
