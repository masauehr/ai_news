## 3. ローカルLLM・小型LLMの進化が加速：Bonsai 27B、BitNet 1.58-bit、GLM-5.2

### Bonsai 27B — スマートフォンで動作可能なLLM

ITmedia AI+が報じた「Bonsai 27B」は、スマートフォンなどのモバイルデバイスで実行可能な270億パラメータのLLMです。ローカル実行環境の拡大により、エッジデバイス上での推論が現実的になってきています。

参照: [ITmedia AI+ — Bonsai 27B](https://www.itmedia.co.jp/aiplus/)

### BitNet b1.58 2B4T — Microsoftの1-bit LLM

Microsoftが開発したBitNet b1.58 2B4Tは、全重みを{-1, 0, +1}の3値に制限する1.58-bit LLMです。Qwen2.5と比較して約12倍のエネルギー効率を実現し、家庭用PCでの実行が可能になっています。

参照: [InfoQ — Microsoft BitNet 1-bit LLM](https://www.infoq.com/news/2025/04/microsoft-bitnet-1bit-llm/)

### GLM-5.2の大規模ローカル実行

colibrìが開発したツールにより、GLM-5.2という7440億パラメータのLLMをメモリ25GBで稼働させることが可能になりました。

参照: [Techno Edge — colibrìがGLM-5.2を25GBメモリで動作](https://www.techno-edge.net/article/2026/07/16/5300.html)

## 4. AIエージェント技術の成熟度と失敗リスク：Gartnerが約50%の失敗率を予測

ITmedia AI+によると、Gartnerの調査では、企業が導入するAIエージェントの約半数が「戦力外」になる可能性があります。Microsoft Agent Frameworkへの転換やMCP（Model Context Protocol）の標準化により、エージェント技術は進化していますが、実装・運用のギャップが課題となっています。

参照: [ITmedia AI+ — AIエージェント失敗率](https://www.itmedia.co.jp/aiplus/), [AINOW — AIエージェント8つの問題点](https://ainow.ai/2026/07/11/278243/)

## 5. 日本の生成AI政策と企業実装の進化

### ガバメントAI「源内」の実証実験が本格化

デジタル庁は7月17日、ガバメントAI「源内」の活用事例を発表しました。冨安デジタル審議官が「源内は相棒」と述べるなど、政府職員向けAI基盤の定着が進んでいます。実証実験では、NTTデータのtsuzumi 2、富士通のTakane 32B、Preferred NetworksのPLaMo 2.0 Primeの3モデルが稼働しており、2027年1月に評価結果が公表される予定です。

参照: [デジタル庁ニュース — ガバメントAI「源内」活用事例](https://www.digital.go.jp/news/)

### JR東日本が生成AIを活用した窓口応答の実証実験を公開

JR東日本は7月17日、みどりの窓口でNECなどと共同開発した生成AIが顧客対応する実証実験を報道公開しました。チケット区間や日時などの聞き取りをAIが担当し、2030年代早期には発券も含めてAIが担える体制を目指しています。

参照: [日本経済新聞、ITmedia AI+ — JR東日本実証実験](https://www.itmedia.co.jp/aiplus/)

### 国産LLMの拡充：LLM-jp-4とSarashina3

国立情報学研究所（NII）は4月3日にLLM-jp-4シリーズをリリース。8Bモデルと32B-A3B（MoE）モデルが、一部のベンチマークでGPT-4oやQwen3-8Bを上回る日本語性能を実現しています。また、ソフトバンク傘下のSB IntuitionsはSarashina3シリーズを6月30日に提供開始し、標準モデルと軽量モデル、3つの専門モデルを用意しています。

参照: [国立情報学研究所 — LLM-jp-4 リリース](https://www.nii.ac.jp/news/release/2026/0403.html), [ITmedia AI+ — Sarashina3登場](https://www.itmedia.co.jp/article/2606/30/2000000143/)

## まとめ

今週は、ローカル・小型LLMの技術進化が特に顕著でした。Bonsai 27B、BitNet 1.58-bit、GLM-5.2など、エッジデバイスでの推論が現実化し、クラウド依存からの脱却が進みつつあります。一方、日本の政府・企業レベルでの生成AI導入も加速しており、ガバメントAI「源内」の実証実験やJR東日本の窓口対応実装など、実装段階に入ってきたことが印象的です。また、AIエージェント技術の失敗リスクが指摘される中、Microsoft Agent FrameworkやMCPなどの標準化が、業界全体の安定化を目指した重要な動きとなっています。
