# 生成AI週次ダイジェスト（9/26〜10/3）

## 主要LLMの新リリースと価格戦略の転換

9月下旬は、OpenAI・Anthropic・Google による大型モデルの連続発表が相次ぎました。

**OpenAI** は9月22日に GPT-6 Sol・Luna、9月29日に GPT-6.1 Sol を発表。Sol は長時間処理向け、Luna は低価格・KVキャッシュ重視設計です。GPT-6.1 Sol は Astraに近い性能ながら標準API料金を5分の1に削減し、価格競争が激化しています。さらに DevDay 2026 では、クラウド上で常時稼働する自律型AIエージェント「Dots」を発表。いずれもAPI呼び出しコストの削減とエージェント化への軸足転換を示しています。

**Anthropic** は9月22日に Claude Opus 5.5 を、9月28日に Claude Sonnet 5.5 を正式リリース。Opus 5.5 は前バージョン比でコスト40%削減・出力速度30%向上を実現し、Claude for Government も一般公開しました。同時に、IPOを予定する中で存在リスクについても情報公開を進めており、安全性と成長の両立を打ち出しています。

**Google** は9月30日、最上位モデル「Gemini 4 Argon」を発表。$2/million tokens という破格の価格設定で、信頼できる用途から段階展開を開始しています。

参照: [OpenAI DevDay 2026（各種発表）](https://openai.com/blog/)、[Anthropic Claude 5.5シリーズ公開](https://www.anthropic.com/news)、[Google Gemini 4 Argon発表](https://www.axios.com/2026/09/30/google-gemini-4)

## FTC調査開始と業界規制の動向

9月30日、米国FTCがOpenAI・Anthropic・METRに対し、AIエージェント関連の安全性主張が消費者保護法違反に該当するかを調査する正式情報要求を開始しました。同時に、トランプ政権はOpenAI・Anthropic・Google DeepMind・Nvidia・Meta・Microsoft・AMD等との間で、「AI安全協約」に署名。自主規制による評価・監査・透明性向上を約束しており、業界的なアプローチの多層化が明らかになっています。

参照: [FTC opens probe into AI giants including Anthropic and OpenAI](https://bnnbloomberg.ca/business/artificial-intelligence/2026/09/30/ftc-opens-probe-into-ai-giants-including-anthropic-and-openai)

## ローカルLLMとOllama のエコシステム拡大

**Ollama v0.35.0** が9月29日に公開され、TypeSafe の Jev API に基づく意思決定API「/v1/systemone」を新たに搭載しました。構造化確率判定（choice / noul / scoreタイプ）に対応し、Bespoke Labs の「nimble 9B」や Together AI の「tev1 4B / 0.8B」が利用可能。M5 Maxでの判定平均は91msと低レイテンシを実現しており、エッジデバイスでの軽量推論の可能性を広げています。

設定改善やmacOS不具合修正も実施され、Ollama は GUI からの ChatGPT デスクトップ連携設定追加（macOS限定）により、CLI不要でローカル実行が可能になりました。

参照: [Ollama v0.35.0 リリースノート](https://localmodelwatch.tsuchitsuchi.com/2026/09/30/ollama-v0350/)、[Ollama 公式](https://ollama.com/)

## 国産LLM と政府AI活用の推進

**国立情報学研究所（NII）** は「LLM-jp-4.1」シリーズを9月17日に発表。約12兆トークンの良質なコーパスで学習され、最大約6万5,000トークンのコンテキスト対応。一部ベンチマークで GPT-4o や Qwen3-8B を上回る日本語性能を達成し、オープンソースライセンスで提供されます。

**デジタル庁** は「ガバメントAI 源内（げんない）」の2026年度大規模実証を進め、全府省庁の約18万人の職員対象に展開予定。政府共用生成AI基盤として国産LLM 7モデルを試用基盤に追加し、データセキュリティと日本語性能の両立を目指しています。2026年9月1日より「行政の進化と革新のための生成AI調達・利活用ガイドライン」も施行され、政府調達のルール整備が完了しています。

参照: [NII LLM-jp-4.1発表](https://www.nii.ac.jp/news/release/2026/0403.html)、[デジタル庁ガイドライン施行](https://www.digital.go.jp/assets/contents/node/information/field_ref_resources/decb64eb-f26e-41cb-8d37-f3dd173108b8/59054b35/20260612_resources_standard_guidelines_guideline_01.pdf)

## AIエージェント開発フレームワークの統合化

Microsoft AutoGen は2025年10月にメンテナンスモード移行が決定。最終版 v0.7.5 は2025年9月30日リリース済みで、新機能追加は終了します。2026年4月1日に **Microsoft Agent Framework（MAF）v1.0 GA** がリリースされ、AutoGen と Semantic Kernel を統合。**MCP（Model Context Protocol）** と **A2A（Agent-to-Agent）** の標準サポートにより、エージェント間通信とツール連携が飛躍的に拡張されました。

実務的には「CrewAI でPoC → LangGraph で本番」が2026年の標準パスとされており、AutoGen の後継選択肢は複数分化しています。

参照: [AutoGen から Microsoft Agent Framework への移行ガイド](https://learn.microsoft.com/ja-jp/agent-framework/migration-guide/from-autogen/)、[MCPサーバーのサポート](https://developer.mamezou-tech.com/blogs/2026/04/24/mcp-impl_introduction/)

## 低ビット量子化LLMと超軽量推論の可能性

Microsoft Research の **BitNet b1.58** は、重みを {-1, 0, +1} の3値（1.58-bit）で表現するネイティブ低ビットモデル。既存の学習後量子化と異なり、学習段階から極端な低ビット化を組み込んでいます。

- **3Bパラメータ**: ラズパイ5で 11 tokens/sec、Apple M2 で 45 tokens/sec
- **x86 CPU**: 標準推論比で 2.37～6.17倍高速、エネルギー消費 71.9～82.2% 削減
- **最大スケール**: 8Bパラメータ（2026年現在）

BitNet a4.8 では4ビット活性化を導入し、BitNet b1.58 と同等の学習コストで高速化を実現しています。エッジAIとCPU推論の実用化フェーズが始まっており、低消費電力デバイスでのAI展開が加速しています。

参照: [BitNet: 1-bit Pre-training for Large Language Models（JMLR）](https://www.jmlr.org/papers/v26/24-2050.html)、[Microsoft BitNet技術解説](https://abeam.tech/media/ai-papers/2026-06-07-bitnet-1bit-pretraining/)

## 実装・体験記事から見える現在地

note.com では、実際に最新AIツールを試してみた実体験記事が増加しています。

- **OpenAI Dots 活用記**: クラウドエージェントが定期的にタスク実行。Google Drive / Gmail 横断検索で生産性向上を実感
- **Gemini Notebook（NotebookLM後継）**: ドキュメント読ませて AI エージェントが要約・質問応答。会議資料や長編テキストの処理に有効
- **Codex マンガ生成実験**: テキストコンテキストから絵コンテを自動生成。従来の手動工程を大幅短縮

これらは、AIが単なる回答ツールから「継続的なアシスタント化」「マルチモーダル統合」「自律実行」へシフトしていることを示しています。一方で、生成AI利用による特許技術の再実装について、「業として」の適用外となる個人利用スコープが拡大しつつあり、ソフトウェア・ツール市場への影響も注視が必要です。
