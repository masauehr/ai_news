# 生成AI週次ダイジェスト（6/20〜6/27）

今週はOpenAIの次世代モデル「GPT-5.6」発表、AnthropicのClaude Opus 4.8およびFable 5/Mythos 5の展開、Google DeepMindのGemini OmniやGemma 4 12Bなど主要3社の動向が非常に活発でした。また日本国内ではデジタル庁「源内」の全府省庁18万人への拡大と国産基盤モデル公募予告、Polimillの自治体向けAI展開など注目すべき動きがありました。

## 1. OpenAI: 次世代AIモデル「GPT-5.6」シリーズを発表 — Sol/Terra/Lunaの3段階命名へ

OpenAIは、次世代AIモデル「GPT-5.6」シリーズとして、フラッグシップ「Sol」、バランス型「Terra」、低コスト高速「Luna」の3種類を発表しました。現在は米国政府との協議を経て信頼できるパートナー企業・組織への限定プレビューとして提供が始まっており、数週間以内に一般公開を計画しています。

**GPT-5.6 Solの主な特徴:**
- 新たに「max」推論モードを導入し、より深い思考時間を確保
- 複数のサブエージェントを活用する「ultra」モードを新設
- コーディング分野ではTerminal-Bench 2.1で最高水準を達成
- サイバーセキュリティ分野ではExploitBenchで競争力を持ちつつ、出力トークン数を約3分の1に削減

**価格体系:**
- Sol: 入力$5 / 出力$30
- Terra: 入力$2.50 / 出力$15（GPT-5.5と競争力のある性能で価格は半分）
- Luna: 入力$1 / 出力$6

また、プロンプトキャッシュの仕様も更新され、明示的なキャッシュブレークポイントのサポートと最低30分のキャッシュ保持が導入されました。7月にはCerebrasプラットフォーム上でGPT-5.6 Solを最大毎秒750トークンの速度で提供開始する予定です。

**情報源:**
- [OpenAI公式ブログ - GPT-5.6発表](https://www.techno-edge.net/article/2026/06/27/5229.html)

## 2. Anthropic: Claude Opus 4.8のリリースとFable 5/Mythos 5の展開 — 超能力モデルの一般公開へ

AnthropicはClaude Opus 4.8をリリースし、コーディング、エージェントスキル、推論、実務知識作業タスクにおいて前版Opus 4.7を上回る性能を示しました。特にSuper-AgentベンチマークではGPT-5.5と同率ながら全ケースをエンドツーエンドで完了した唯一のモデルとなり、Legal Agent Benchmarkでも10%以上のall-passを記録する初のモデルとなりました。

**Claude Opus 4.8の主な改善点:**
- コーディングとエージェント作業においてより信頼性が高く、判断が鋭敏
- ツール呼び出しが効率化され、同じ知能で fewer steps で完了
- 不正な主張に対して約4倍少なく許容する「誠実性」の向上
- Opus 4.8 fast modeは従来比3倍安く、2.5倍速い

**Claude Fable 5 / Mythos 5:**
さらにAnthropicはMythosクラスのモデル「Fable 5」を一般利用向けに安全化して公開しました。Fable 5はソフトウェアエンジニアリング、知識作業、ビジョン、科学研究などほぼ全てのベンチマークでSOTAを示し、Stripeでは「月単位だったコードベース移行を1日で完了」との評価を得ています。またMythos 5はサイバー防御者やインフラプロバイダー向けにProject Glasswingを通じて提供され、世界最強のサイバーセキュリティ能力を持つとされています。

価格も$10/百万入力トークン、$50/百万出力トークンで、Mythos Previewの半分以下となっています。

**情報源:**
- [Anthropic - Claude Opus 4.8](https://www.anthropic.com/news/claude-opus-4-8)
- [Anthropic - Claude Fable 5 and Mythos 5](https://www.anthropic.com/news/claude-fable-5-mythos-5)

## 3. Google DeepMind: Gemini Omniの発表とGemma 4 12Bのリリース、Computer Use統合

Google DeepMindは今週複数の重要なモデル発表を行いました。

**Gemini Omni:**
新しいモデル「Gemini Omni」を発表し、推論能力と創造能力を融合させました。まずはビデオ生成に特化した「Gemini Omni Flash」がGeminiアプリ、Google Flow、YouTube Shortsにロールアウトされています。自然言語によるビデオ編集が可能で、プロンプト例として「スカルプチャをバブルにする」「鏡に触れたら液体のように波立たせる」などの高度な操作がデモされています。

**Gemma 4 12B:**
ローカル推論向けに「Gemma 4 12B」をリリースしました。16GB VRAMのラップトップで動作可能であり、マルチモーダル（ビジョン・オーディオ入力）に対応しています。エンコーダーフリーアーキテクチャを採用し、ビジョンとオーディオ入力を直接LLMバックボーンにフローさせることでレイテンシを削減しています。Apache 2.0ライセンスでHugging FaceやKaggleからダウンロード可能です。

**Gemini 3.5 FlashのComputer Use統合:**
「Gemini 3.5 Flash」にコンピューターの画面を認識して操作を実行する「Computer Use」機能を組み込みツールとして統合しました。これにより開発者はブラウザ、モバイル、デスクトップ環境全体で認識・推論・アクションを実行できるカスタムエージェントを構築できるようになります。プロンプトインジェクション対策として敵対的トレーニングやユーザー確認必須機能、自動停止機能などを多層的に実装しています。

**Gemini 3.5 Live Translate:**
音声モデル「Gemini 3.5 Live Translate」もリリースされ、70以上の言語を自動検出し、話者のイントネーション・ペース・ピッチを保持した滑らかな翻訳音声を生成します。Google MeetやGoogle Translateアプリにロールアウトされています。

**情報源:**
- [Google DeepMind - Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)
- [Google DeepMind - Introducing Gemma 4 12B](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/)
- [Google DeepMind - Computer Use in Gemini 3.5 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)
- [Google DeepMind - Gemini 3.5 Live Translate](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-live-3-5-translate/)

## 4. AIエージェント・MCP動向: HuggingFaceのMoon BotとCanva MCP、AutoGen最新

**HuggingFace Moon Bot:**
HuggingFaceはSlackネイティブのコーディングエージェント「Moon Bot」を公開しました。Pi coding agent SDKとHuggingFace Bucketsを活用し、ElasticsearchログやMongoDBデータベースへの直接クエリ、GitHub PR作成、コードベースの閲覧などをSlackスレッド上で完結させます。セッション履歴はJSONL形式でBucketに保存され、エージェントトレースビューアで監査可能です。

**Canva MCP:**
Canva MCPの解説記事が注目されており、自然言語だけでデザイン作成・修正・書き出しを7つの機能で実現する方法が紹介されています。Instagram用1080×1080画像を数秒で作成し、10枚以上の一括生成やPPTX出力も可能です。

**AutoGen:**
MicrosoftのAutoGenはマルチエージェントAIアプリケーションフレームワークとして生産環境への移行が進んでおり、AF（Agent Framework）が製品版として利用可能となっています。

- [Canva MCP解説 - Hakky Handbook](https://book.st-hakky.com/data-science/what-is-canva-mcp-7-features)

## 5. ローカルLLM・画像生成: Krea 2とBoogu-Image、Ollamaエコシステムの拡大

**Krea 2:**
6月23日、Krea Projectから「Krea 2」がオープンウェイトでリリースされました。12BパラメータのRaw（ベース）とTurbo（蒸留済み高速版）の2種類で、最大2048×2048に対応します。特徴的なのは学習データにAI画像を一切使っていない点です。ComfyUI、ai-toolkit、Musubi Tunerがday 0対応しており、Hugging Faceにはfp8版やgguf版などの派生モデルも登場しています。ライセンスは商用利用OKですが年商100万ドル以上の企業はEnterprise Licenseが必要です。

**Boogu-Image-0.1:**
6月16日、Boogu Projectから「Boogu-Image-0.1」がリリースされました。Base、Turbo、Editの3バリアントからなる統合画像生成・編集モデルファミリーでパラメータは全て10B（Qwen3vl_8b）。Apache-2.0ライセンスです。

**Ollamaエコシステム:**
2026年6月時点でOllamaライブラリには4,500以上のモデルが並び、MetaのLlama 4、AlibabaのQwen3、GoogleのGemma 4、DeepSeek-R1、MicrosoftのPhi-4、Mistralなどをollama pullできます。推論最強はDeepSeek-R1 7B/14B、コーディング最強はKimi K2.6やQwen 3.6 27B、Devstral Small 24Bなどが注目されています。

**情報源:**
- [Techno Edge - Boogu-Image-0.1とKrea 2](https://www.techno-edge.net/article/2026/06/25/5223.html)
- [PromptQuorum - Ollamaおすすめモデル2026年6月](https://www.promptquorum.com/ja/local-llms/top-open-source-models-ollama)

## 6. デジタル庁「源内」の全府省庁18万人への拡大と国産基盤モデル公募予告

**ガバメントAI「源内」の大規模実証:**
デジタル庁は2026年5月からガバメントAI「源内」の大規模実証実験を開始しました。5月29日時点で約10万人の政府職員が利用可能となっており、今後全府省庁の約18万人が利用できるよう環境整備を進めています。国会答弁検索AIや法制度調査支援AIなど行政実務を支援する複数のアプリケーションを提供し、行政現場での利用状況や課題を検証しています。

**国産基盤モデル公募予告:**
デジタル庁は令和9年度（2027年度）向けにガバメントAI「源内」で使用する国産基盤モデルの公募を2026年11月に実施予定であることを発表しました。今年度は15件の応募があり5社との契約を締結し、評価検証を行っています。来年度向けの調達（有償）を実施する予定で、今年度の評価検証結果も考慮されます。

**生成AI調達ガイドライン第2.0版:**
6月12日、「行政の進化と革新のための生成AIの調達・利活用に係るガイドライン（第2.0版）」を策定しました。第23回デジタル社会推進会議幹事会において決定され、生成AI技術の進展や活用領域の拡大、国内外の制度・政策動向を踏まえて改定が行われました。
