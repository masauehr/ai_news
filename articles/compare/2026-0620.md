# 生成AI週次ダイジェスト（6/13〜6/20）

今週も生成AI分野は急速に進化しています。Google DeepMindによる新モデル発表やOpenAIのS-1提出、デジタル庁のガイドライン改定など、注目トピックが多数ありました。

## 1. Google DeepMind: Gemini Omni と Gemma 4 12B を発表

Google DeepMindは、5月下旬に「Gemini Omni」を発表しました。これはあらゆるインプット（画像・音声・動画・テキスト）からあらゆるアウトプットを生成するマルチモーダルモデルです。特に注目すべきは、自然言語による対話と推論能力を活用した動画の生成・編集機能で、YouTube ShortsやGoogle Flowでの提供が開始されています。

また、「Gemma 4 12B」も発表され、エンコーダーフリーの統一マルチモーダルモデルとして登場しました。これにより、より高速なテキスト生成（DiffusionGemmaによる4倍高速化など）が可能になっています。

- [Introducing Gemini Omni](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)
- [Introducing Gemma 4 12B: a unified, encoder-free multimodal model](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/)

## 2. Anthropic: Claude Opus 4.8 と Fable Mythos Access

Anthropicは「Claude Opus 4.8」を発表しました。これはClaude Code向けのEnterprise/Team/Maxプランで利用可能で、長時間実行されるタスクの処理能力が強化されています。同時に、「dynamic workflows」の研究プレビューも導入されました。

また、「Fable Mythos Access」に関する発表もあり、AnthropicのパブリックレコードやプロジェクトGlasswingの拡大など、パートナーシップの深化が進んでいます。なお、6月12-13日頃にClaude Fable 5とMythos 5が一時的に停止されたという報告もありますが、Opus 4.8やSonnet 4.6は影響を受けていません。

- [Claude Opus 4.8](https://www.anthropic.com/news/claude-opus-4-8)
- [Claude Fable 5 Mythos 5](https://www.anthropic.com/news/claude-fable-5-mythos-5)
- [Fable Mythos Access](https://www.anthropic.com/news/fable-mythos-access)

## 3. OpenAI: S-1提出とChatGPT新機能、そして「1x1 Health Art」

OpenAIは6月8日、SECへS-1を秘密裏に提出したことを確認しました。IPOに向けた重要な一歩です。

また、ChatGPTアプリでは6月18日頃に「1x1 Health Art」と呼ばれる健康知能の改善機能が導入されました。さらに、ChatGPTには定期タスク実行の新機能「スケジュール」が追加され、入荷確認や毎朝のまとめを自動化して通知する使い方が可能になっています。

- [Confidential submission of draft S-1 to the SEC](https://openai.com/index/openai-submits-confidential-s-1/)
- [Built to benefit everyone: our plan](https://openai.com/index/built-to-benefit-everyone-our-plan/)
- [ChatGPTに定期タスク実行の新機能「スケジュール」](https://www.techno-edge.net/article/2026/06/19/5205.html)

## 4. Microsoft Agent Framework: AutoGenから次世代へ移行

MicrosoftはAutoGenとSemantic Kernelを統合した「Microsoft Agent Framework (MAF)」への移行を進めています。AutoGenは2026年時点でメンテナンスモードに入っており、新規採用はMAFが推奨されています。MAF 1.0はGA（General Availability）を迎え、A2A/MCP対応や状態耐久性HITL、Observabilityなどが強化されています。

- [AutoGen から Microsoft Agent Framework への移行ガイド](https://learn.microsoft.com/ja-jp/agent-framework/migration-guide/from-autogen/)
- [Microsoft Agent Frameworkとは？AutoGenとSemantic Kernelを統合する次世代AIエージェント基盤【2026年版】](https://arpable.com/artificial-intelligence/agent/microsoft-agent-framework/)

## 5. デジタル庁: 「源内」の実績公開とガイドライン第2.0版改定

デジタル庁は、ガバメントAI「源内」の利用実績を公表しました。3か月の利用状況がまとめられ、行政全体へのAI実装促進に向けた先行事例として注目されています。

また、「生成AIの調達・利活用ガイドライン」第2.0版を策定しました。技術進展や制度動向を踏まえた改定で、政府共用生成AI基盤における国産LLM7件の選定（「7人の侍」）も進んでいます。

- [デジタル庁職員による生成AIの利用実績に関する資料を掲載しました](https://www.digital.go.jp/news/08ded405-ca03-48c7-9b92-6b8878854a74)
- [デジタル庁、「生成aiの調達・利活用ガイドライン」第2.0版を策定](https://japansecuritysummit.org/2026/06/14565/)
- [ガバメントAI「源内」をオープンソースとして公開します](https://digital-gov.note.jp/n/n84aeba282e60)

## 6. ローカルLLM: OllamaとBitNetの進化

Ollamaは引き続きローカルLLM実行ツールとして人気を集めており、WindowsやMacでの導入ガイドが多数投稿されています。プライバシー重視のプライベートAI活用が進んでいます。

また、Microsoftの1-bit LLM推論フレームワーク「BitNet」も注目されており、bitnet-b1.58シリーズなどがHuggingFaceでトレンドを形成しています。1-bitモデルはメモリ使用量を大幅に削減し、エッジデバイスでの展開が期待されています。

- [Ollama とは何か、どう始めるか:2026年ローカル LLM 完全ガイド](https://pasqualepillitteri.it/en/news/3703/what-is-ollama-how-to-get-started-2026-guide)
- [GitHub - microsoft/BitNet: Official inference framework for 1-bit LLMs](https://github.com/microsoft/BitNet)

## 7. Note記事: 生成AIの使ってみた感想

今週のNote記事では、以下のような生成AI関連の投稿が注目されています。

- [主要生成AIツール4選 徹底比較！～ChatGPT・Claude・Gemini・Microsoft 365 Copilotの違いとは？～｜ウチダ人材開発センタ（UHD）公式note](https://note.com/uhd_7ship/n/nd8b6f3840995)

## 8. その他注目ニュース

- **Midjourneyのハードウェア参入**: Midjourneyが超音波CT「Midjourney Scanner」を備えた「次世代スパ」を2027年中にオープン予定と発表。
- **Google HomeにGemini搭載**: 新しいGoogle Homeスピーカーが発売され、Geminiによるライブ会話対応が開始されました。

# 生成AI週次ダイジェスト（6/13〜6/20）

## 🎯 今週のハイライト

2026年6月の第2週は、大規模言語モデルの新展開、エージェントAIの進化、日本国内の生成AI推進施策が相次いで発表された重要な週となりました。特にGoogleの新モデル発表、ChatGPTの定期実行機能、そして国産LLM選定に関する重大なニュースが注目を集めました。

---

## 📰 主要トピック

### 1. **Google、Gemini Omni と Gemma 4 12B を発表**
GoogleのDeepMindチームが複数の大規模言語モデルの新版を発表しました。特に注目は「Gemini Omni」と「Gemma 4 12B」で、後者はエンコーダー不要の統合マルチモーダルモデルとして位置づけられています。

- 出典: [Introducing Gemini Omni（Gemini Omniの発表）](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)
- 出典: [Introducing Gemma 4 12B（Gemma 4 12Bの発表）](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemma-4-12b/)

Googleはさらに「DiffusionGemma」という4倍高速なテキスト生成技術も公開し、推論効率の向上に注力している様子が伺えます。

### 2. **ChatGPT、定期タスク実行機能「スケジュール」を追加**
OpenAIはChatGPTに「タスク（Scheduled Tasks）」という新機能を追加し、定期的に実行されるワークフローの自動化を可能にしました。入荷確認やユーザーの毎朝のまとめ作成などが自動実行できるようになります。

- 出典: [ChatGPTに定期タスク実行の新機能「スケジュール」](https://www.techno-edge.net/article/2026/06/19/5205.html)

この機能により、生成AIの活用範囲が「会話相手」から「自動執行エージェント」へ拡大しています。

### 3. **Google、Gemini搭載スマートスピーカーを1万6800円で発売**
Googleは新型の「Google Home」スマートスピーカーを発表。Geminiを搭載し、定型文以外の複雑なフレーズやコマンドに対応できるようになりました。サブスクリプションオプションでのライブ会話機能も提供予定です。

- 出典: [Gemini搭載の新Google Homeスピーカー発売](https://www.techno-edge.net/article/2026/06/18/5199.html)

### 4. **【国内動向】デジタル庁、全府省庁18万人向けの「源内」実証を5月から開始。国産LLM 7件を選定**

日本のAI戦略における最重要ニュースが本週です。デジタル庁は「ガバメントAI」構想の中核となる生成AI利用環境「源内（げんない）」を、2026年5月から全府省庁約18万人の職員を対象に大規模実証を開始しました。

**選定された国産LLM 7件（「7人の侍」）：**
- NTTデータの「PLaMo」シリーズ
- Sarashina 2
- その他5件の国産モデル

- 出典: [デジタル庁が国産ai「7人の侍」選定](https://www.sbbit.jp/article/cont1/182108/)
- 出典: [政府の生成AI基盤「源内」とは](https://note.com/zouplans/n/nb7d48809d758/)
- 出典: [ガバメントAI「源内」をオープンソースとして公開](https://digital-gov.note.jp/n/n84aeba282e60/)

この施策は単なる行政デジタル化ではなく、国産LLM産業の育成と日本語特化型AI開発を国家レベルで推進する重要なシグナルとなっています。

### 5. **国立情報学研究所（NII）、LLM-jp-4シリーズを公開。GPT-4o越えの日本語性能を達成**
4月3日に国立情報学研究所は新型国産LLM「LLM-jp-4」シリーズを発表。約12兆トークンの良質コーパスで学習し、複数のベンチマークでOpenAIの「gpt-oss-20b」やQwen3-8Bを上回る日本語処理性能を実現しました。

公開されたモデル：
- LLM-jp-4 8Bモデル
- LLM-jp-4 32B-A3Bモデル（アーキテクチャ専用）

- 出典: [国立情報学研究所の LLM-jp-4 公開](https://www.nii.ac.jp/news/release/2026/0403.html)
- 出典: [NIIが12兆トークン国産LLM、日本語性能でGPT-4o越え](https://www.sbbit.jp/article/cont1/183900/)
- 出典: [国産LLM「LLM-jp-4」公開](https://note.com/pika2_hikaru/n/n11992fb9e79e/)

### 6. **1兆パラメータの中国系コーディングAI「Kimi-K2.7-Code」が無料・商用利用可で登場**
中国のAI企業が開発した1兆パラメータのコーディング特化モデル「Kimi-K2.7-Code」が無料で商用利用可能な状態で公開されました。また、アリババの衛星画像3D生成AI「ABot-Earth 0.5」も注目を集めています。

- 出典: [1兆パラメータのコーディングAI「Kimi-K2.7-Code」が無料・商用利用可](https://www.techno-edge.net/article/2026/06/19/5203.html)

### 7. **AI業界の新展開：Midjourneyのハードウェア参入、xAIの新型スパの発表**
話題のAI画像生成企業Midjourneyが次のステップとして、超音波CT「Midjourney Scanner」を備えた「次世代スパ」を2027年中にオープンすることを発表。AIの利用シーンが医療・ウェルネス領域へも拡大しています。

- 出典: [Midjourneyがハードウェアに参入](https://www.techno-edge.net/article/2026/06/18/5200.html)

### 8. **AIエージェントとMCP（Model Context Protocol）の統合進化**
OpenAIとMicrosoftがModel Context Protocol（MCP）への対応を発表したことで、AIエージェントと外部システム・ツールの連携が標準化されつつあります。AutoGenなどのエージェントフレームワークもMCP対応が進み、「AI界のUSB-C化」が現実化しています。

- 出典: [Claudeに記憶を持たせてみた〜MCPとMemory機能の導入](https://qiita.com/natsugure/items/a887aa86bfdf39bb2104/)
- 出典: [What is the Model Context Protocol（MCP）?](https://modelcontextprotocol.io/)

### 9. **1-bit LLM「BitNet」の進化：超効率的なローカルLLM実行の現実化**
Microsoftが開発した1-bit LLM「BitNet」が100億パラメータ規模の実用化段階に入りました。重みを{-1, 0, 1}の3値で表現することで、CPUでの推論を可能にし、エネルギー効率と処理速度の革新的な改善を実現しています。

- 出典: [BitNet a4.8: 4-bit Activations for 1-bit LLMs](https://www.microsoft.com/en-us/research/publication/bitnet-a4-8-4-bit-activations-for-1-bit-llms/?lang=ja)
- 出典: [BitNet 100B Models on CPU](https://api7.ai/ja/blog/bitnet-100b-cpu-intelligent-llm-routing)

### 10. **生成AIの企業活用：経営企画・資料作成・顧客対応の効率化が進展**
国内では生成AIの企業導入がさらに加速。経営企画部門での活用、営業資料の自動生成、社内問い合わせ対応の自動化など、業務プロセス全体への浸透が報告されています。

- 出典: [生成AIを経営企画に活用する方法](https://ainow.ai/2026/06/20/278185/)
- 出典: [生成AIで社内問い合わせを自動化](https://ainow.ai/2026/06/16/278175/)
- 出典: [生成AIで資料作成を効率化する方法](https://ainow.ai/2026/06/16/278172/)
