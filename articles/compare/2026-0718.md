# 生成AI週次ダイジェスト（7/11〜7/18）

今週も生成AI界隈は激しく動きました。OpenAIが初のハードウェア「Codex Micro」を発売、AnthropicはClaude Sonnet 5のグローバル展開とFable 5のエクスポート規制解除、Google DeepMindはGemini Omni Flashを発表しました。日本国内では、デジタル庁のガバメントAI「源内」活用事例やSB Intuitionsによる国産LLM「Sarashina3」の提供開始など、実装フェーズが加速しています。

---

## 1. OpenAI: 初のハードウェア製品「Codex Micro」発売

OpenAIは、キーボードメーカーWork Louderと共同開発したキーパッド「Codex Micro」の販売を開始しました。[出典: Techno Edge](https://www.techno-edge.net/article/2026/07/16/5299.html)

- **概要**: AIコーディングエージェント「Codex」の操作に特化したキーパッド。230ドルで数量限定販売（7月24日頃出荷）。
- **特徴**: LED付き6キーでエージェントのステータスを視覚化、コード承認・却下や推論レベル切替ダイヤルなどを物理ボタンで操作可能。
- **背景**: OpenAIは昨年アップルの元デザイン責任者ジョナサン・アイブ社io Productsを買収しハードウェア参入を示唆していましたが、実際に発売されたのはエージェント操作専用デバイスでした。

---

## 2. Anthropic: Claude Sonnet 5グローバル展開、Fable 5のエクスポート規制解除

AnthropicはClaude Sonnet 5を全プランでデフォルトモデルとして展開すると同時に、米政府によるエクスポート規制の解除を受けてClaude Fable 5のアクセスを再開しました。[出典: Anthropic Blog](https://www.anthropic.com/news/claude-sonnet-5) [出典: Anthropic Blog (Fable 5)](https://www.anthropic.com/news/redeploying-fable-5)

### Claude Sonnet 5
- **概要**: 「最もエージェント的なSonnetモデル」として、Opus 4.8に迫る性能を低価格で提供。
- **性能**: 推論・ツール使用・コーディング・知識作業においてSonnet 4.6から大幅改善。サイバーセキュリティタスクの実行能力はOpusより低い（安全性向上）。
- **価格**: 2026年8月31日まで入力$2/M、出力$10/M（その後$3/$15に上昇）。Free/Proプランのデフォルトモデルに採用。

### Claude Fable 5 / Mythos 5 エクスポート規制
- 6月12日、米政府がFable 5とMythos 5へのエクスポート管制を適用し、一時的に全ユーザーのアクセスを停止。Amazon研究者によるガードrailバイパス報告が要因。
- 6月30日に管制解除。7月1日よりFable 5はグローバルで再開放（Pro/Max/Teamプランで週使用量の50%まで無料）。Mythos 5は米国内のProject Glasswingパートナーに限定再開。
- AnthropicはAmazon・Microsoft・Googleと共同で、モデルのガードrailバイパス（jailbreak）を評価する共通フレームワークの開発を開始。

### Anthropic: 「Hard Questions」イニシアチブ
- AIの雇用・社会・科学・医療への影響について一般から「難しい質問」を公募し、自社の対応を透明に報告する取り組みを発表。[出典: Anthropic Blog](https://www.anthropic.com/news/hard-questions)

---

## 3. Google DeepMind: Gemini Omni Flash公開、Computer Use in Gemini 3.5 Flash

Google DeepMindはマルチモーダル生成モデル「Gemini Omni」の第一弾「Gemini Omni Flash」をリリースしました。[出典: Google DeepMind Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni/)

- **Gemini Omni Flash**: 画像・音声・動画・テキストを入力として組み合わせ、高品質な動画を生成。会話による動画編集（キャラクターの一貫性保持、物理法則の理解、複数ターンでの refinement）に対応。YouTube ShortsやGoogle Flowで無料利用可能。
- **Computer Use in Gemini 3.5 Flash**: Gemini 3.5 Flashにコンピュータ操作機能を搭載。[出典: Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)

### その他のGoogle DeepMind動向
- **DiffusionGemma**: 4倍高速なテキスト生成を実現する拡散ベースのGemmaモデル。[出典: Google Blog](https://blog.google/innovation-and-ai/technology/developers-tools/diffusion-gemma-faster-text-generation/)
- **AI Agent Safety**: AIエージェントのセキュリティに関する「AI Control Roadmap」を公開。MITRE ATT&CKフレームワークに基づく脅威モデリングや、スーパーバイザーAIによる監視・防止メカニズムを解説。[出典: DeepMind Blog](https://deepmind.google/blog/securing-the-future-of-ai-agents/)
- **Nano Banana 2 Lite**: Gemini Omni Flash用の軽量モデル。[出典: Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-omni-flash-nano-banana-2-lite/)

### NotebookLM → Gemini Notebook改称
GoogleはAIリサーチアシスタント「NotebookLM」を「Gemini Notebook」に改名。セキュアなクラウドコンピュータ機能を追加し、コード実行や複雑なデータ分析に対応。Google検索のAIモードとの統合も予定。[出典: Techno Edge](https://www.techno-edge.net/article/2026/07/17/5303.html)

---

## 4. ローカルLLM / オープンソース: colibrìでGLM-5.2を25GBメモリで稼働、NVIDIA Nemotron 3 EmbedがRTEB No.1

### colibrì: 7440億パラメータGLM-5.2を家庭用PCで動作
テンセント系のMoEモデル「GLM-5.2」（7440億パラメータ）を、メモリ25GBの家庭用PCで動かすツール「colibrì」が注目されています。[出典: Techno Edge](https://www.techno-edge.net/article/2026/07/16/5300.html)

- **仕組み**: MoE構造を活用し、常に使用される部分（約9.9GB）をメモリに保持、2万個以上のエキスパート（合計約370GB）はSSDに保存して必要な時だけ読み込み。よく使われるエキスパートは自動的にメモリに固定され、使うほど高速化。
- **パフォーマンス**: キャッシュ未状態では毎秒0.05〜0.1トークン。128GBメモリ搭載のApple M5 Maxでは約1トークン/秒まで向上。

### NVIDIA Nemotron 3 Embed: RTEBリーダーボードで総合No.1
NVIDIAは埋め込みモデル「Nemotron 3 Embed」コレクションを公開。8BモデルがRTEB（Retrieval-Augmented Evaluation Benchmark）で総合1位を達成。[出典: Hugging Face Blog](https://huggingface.co/blog/nvidia/nemotron-3-embed-wins-rteb)

- **ラインアップ**: 8B-BF16、1B-BF16、1B-NVFP4（Blackwell最適化4bit）。
- **特徴**: 32kコンテキストウィンドウ、マルチリンガル・コード対応。エージェントの検索精度向上によりダウンストリームのトークンコストを削減。

### Hugging Face / three.ws: AIエージェントに3Dボディとウォレット
Hugging Faceが紹介したthree.wsは、AIエージェントに3Dボディ（アニメーション可能なメッシュ）とオンチェーンウォレット（USDC支払い機能）を提供するプラットフォーム。[出典: Hugging Face Blog](https://huggingface.co/blog/three-ws/giving-ai-agents-bodies-and-wallets)

- 18,000以上のアバター、2,800以上のエージェントが参加。
- HTTP 402（Payment Required）ステータスコードを復活させ、エージェント間での自動決済を実現。

## 5. テンセント Hy3: 2950億パラメータMoEモデルを無償公開

テンセントのHunyuanチームは、2950億パラメータ（実行時210億パラメータ稼働）のMoEモデル「Hy3」をApache 2.0ライセンスでオープンウェイト公開。[出典: Techno Edge](https://www.techno-edge.net/article/2026/07/17/5304.html)

- **性能**: 270名の専門家によるブラインド評価で競合モデルを上回り、特にプログラミング・システム開発分野で高評価。ハルシネーション率12.5%→5.4%に改善。
- **特徴**: 最大256Kコンテキスト対応。外部API通信不要のローカル推論にも対応。

### claude-real-video: AIに動画を「ちゃんと」見せるツール
AIが動画を認識しない問題を解決するオープンツール「claude-real-video」が無償公開。[出典: Techno Edge](https://www.techno-edge.net/article/2026/07/17/5304.html)

- シーンの切り替わりを検知して意味のあるフレームのみを抽出（例: 58秒動画→26枚の画像）。
- Whisperによる自動文字起こしも実施。ローカル実行で動画が外部にアップロードされない。

### ternlight: 5MBのWebAssembly埋め込みAIライブラリ
推論エンジン・モデル・トークナイザを5〜7MBのWebAssemblyファイルに内包した軽量ライブラリ。BitNet b1.58の3値量子化（-1, 0, 1）を採用し、CPUのみで動作。オフライン対応。[出典: Techno Edge](https://www.techno-edge.net/article/2026/07/17/5304.html)

### LingBot-World 2.0: 1時間生成し続けるAIワールドモデル
ユーザー操作に応じてリアルタイムで映像を生成し続けるインタラクティブワールドモデル。[出典: Techno Edge](https://www.techno-edge.net/article/2026/07/17/5304.html)

- 従来モデルの誤差蓄積問題を克服し、1時間超の連続生成でも画質劣化なし。720p・60fpsストリーミング対応。
- パイロットエージェント（行動計画）とディレクターエージェント（コンテンツ追加）の連携により自律的世界展開。

## 6. 日本国内動向: デジタル庁「源内」活用事例公開、SB Intuitionsが国産LLM「Sarashina3」提供開始

### デジタル庁: ガバメントAI「源内」活用事例・大規模データセット整備
デジタル庁は7月17日、冨安デジタル審議官によるガバメントAI「源内」の活用事例を公開。[出典: デジタル庁](https://www.digital.go.jp/policies/genai/movie_20260717)

- **活用内容**: 英語原稿作成（柱建て提案→翻訳アプリ）、SEABIS（旅費精算システム）Q&Aアプリ（問い合わせ1割削減、レクチャー時間3割減）、引継ぎ資料作成、Lawsy（法制度調査）。
- **将来展望**: AIエージェントの利用環境導入検討、国産LLMの試験的利用開始。

また7月14日、TOPPAN・NTTデータ・FPSCは「ガバメントAI源内」のための大規模データセット整備事業を発表。[出典: EnterpriseZine](https://enterprisezine.jp/news/detail/24679)

- 政府共通データ・ドメイン特化データの収集・OCR前処理・メタデータ設計・AI向けデータセット標準の検討を2027年3月までに実施。

### SB Intuitions: 国産LLM「Sarashina3シリーズ」提供開始
ソフトバンク傘下のSB Intuitionsは6月30日、国産LLM「Sarashina3シリーズ」の提供を開始。[出典: ITmedia AI+](https://www.itmedia.co.jp/aiplus/article/2606/30/2000000143/)

- **モデル構成**: 標準モデル「Sarashina3 mini」、軽量モデル「Sarashina3 nano」、ガードモデル「Sarashina3 guard」、埋め込みモデル「Sarashina3 embedding」、リランキングモデル「Sarashina3 rerank」の5種類。
- **技術特徴**: 日本語・英語中心の30兆トークン超で事前学習。事後学習では外部高性能モデルを使わない「OPSD（オンポリシー自己蒸留）」と強化学習を組み合わせ、高品質な日本語出力を実現。
- **性能**: Sarashina3 miniはQwen3-235BやGPT-5.4 miniと同等性能。SoftBank Cloud PF Type A（Oracle基盤・国内データセンター）で提供。

### NII LLM-jp-4: 国産LLMのオープンソース公開（参考）
国立情報学研究所は4月、LLM-jp-4 8Bモデル・32B-A3Bモデルをオープンソース公開。日本語MT-Benchでgpt-oss-20bやGPT-4oを上回る性能を示した。[出典: ITmedia AI+](https://www.itmedia.co.jp/aiplus/articles/2604/03/news092.html)

## 3. ローカルLLM・小型LLMの進化が加速：Bonsai 27B、BitNet 1.58-bit、GLM-5.2

### Bonsai 27B — スマートフォンで動作可能なLLM

ITmedia AI+が報じた「Bonsai 27B」は、スマートフォンなどのモバイルデバイスで実行可能な270億パラメータのLLMです。ローカル実行環境の拡大により、エッジデバイス上での推論が現実的になってきています。

### BitNet b1.58 2B4T — Microsoftの1-bit LLM

Microsoftが開発したBitNet b1.58 2B4Tは、全重みを{-1, 0, +1}の3値に制限する1.58-bit LLMです。Qwen2.5と比較して約12倍のエネルギー効率を実現し、家庭用PCでの実行が可能になっています。

参照: [InfoQ — Microsoft BitNet 1-bit LLM](https://www.infoq.com/news/2025/04/microsoft-bitnet-1bit-llm/)

### GLM-5.2の大規模ローカル実行

colibrìが開発したツールにより、GLM-5.2という7440億パラメータのLLMをメモリ25GBで稼働させることが可能になりました。

## 5. 日本の生成AI政策と企業実装の進化

### ガバメントAI「源内」の実証実験が本格化

デジタル庁は7月17日、ガバメントAI「源内」の活用事例を発表しました。冨安デジタル審議官が「源内は相棒」と述べるなど、政府職員向けAI基盤の定着が進んでいます。実証実験では、NTTデータのtsuzumi 2、富士通のTakane 32B、Preferred NetworksのPLaMo 2.0 Primeの3モデルが稼働しており、2027年1月に評価結果が公表される予定です。

参照: [デジタル庁ニュース — ガバメントAI「源内」活用事例](https://www.digital.go.jp/news/)

### JR東日本が生成AIを活用した窓口応答の実証実験を公開

JR東日本は7月17日、みどりの窓口でNECなどと共同開発した生成AIが顧客対応する実証実験を報道公開しました。チケット区間や日時などの聞き取りをAIが担当し、2030年代早期には発券も含めてAIが担える体制を目指しています。

参照: [日本経済新聞、ITmedia AI+ — JR東日本実証実験](https://www.itmedia.co.jp/aiplus/)
